# Branding assets

Place the original logo file here as `logo-original.jpg` (exactly this name).

- Do not crop, recolor or add effects: the `Logo` component renders it with its own aspect ratio.
- While the file is missing, the site falls back to a typographic wordmark
  ("Nomi Nebentzhal / CAKES AND BOUTIQUE CONDITORIA").
- The owner can later replace the logo from Admin → Settings → Logo (uploads go to Supabase Storage
  and take precedence over this file).
